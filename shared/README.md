# Shared Workspace (`@elo-organico/shared`)

Common tooling, configuration presets, and Git validation infrastructure across the Elo Orgânico monorepo.

---

## 1. Architecture Overview

Houses shared ESLint configs, Prettier presets, and Husky git validation hooks.

---

## 2. Directory Navigation

- `config/`: Shared configuration presets.
- `git/`: Git lifecycle hooks and commit verification scripts.
